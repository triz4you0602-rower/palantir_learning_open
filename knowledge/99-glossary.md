# 99 · 용어집 (Glossary)

핵심 개념을 영어 병기로 빠르게 참조. 상세는 각 문서 링크로.

| 용어 (KO) | Term (EN) | 한 줄 정의 |
|---|---|---|
| 전진 배치 엔지니어 | **FDE** (Forward Deployed Engineer) | 고객 환경 내부에 임베드되어 프로덕션 코드를 직접 짜는 풀스택 엔지니어. → [01](01-fde-model.md) |
| 델타 | **Delta** | FDE 중 소프트웨어 엔지니어 역할. 프로덕션급 코드·파이프라인·온톨로지 모델링. |
| 에코 | **Echo** (Deployment Strategist) | 도메인 전문가 출신. 미션 현실을 기술 요구로 번역, 채택·정치 담당. |
| 온톨로지 | **Ontology** | 조직의 디지털 트윈. "지저분한 현실의 지도." → [03](03-ontology.md) |
| 객체 타입 | **Object Type** | 현실 개체/이벤트의 스키마 정의 (≈ 테이블). |
| 링크 타입 | **Link Type** | 두 객체 타입 사이 관계의 스키마 정의 (≈ 그래프 엣지). |
| 행동 타입 | **Action Type** | 사용자가 데이터에 가할 수 있는 변경 집합의 스키마 정의 (거버넌스된 쓰기). |
| 함수 | **Function** | 온톨로지와 통합된 코드 로직. |
| 의미 계층 | **Semantic Layer** | 세계가 무엇으로 이루어졌는가 (개체·관계). |
| 동적 계층 | **Kinetic Layer** | 그 세계에서 무엇을 할 수 있는가 (행동·로직). |
| 자갈길→고속도로 | **Gravel Road → Paved Highway** | 특정 고객용 거친 해결책 → 반복 패턴 추출 → 재사용 플랫폼 기본요소. → [01](01-fde-model.md) |
| 그라운드 트루스 | **Ground Truth** | 문서가 아닌 현장의 실제 진실. 몰입으로만 얻음. |
| 하중 임시방편 | **Load-bearing Workaround** | 수년간 보이지 않게 시스템을 지탱해온 임시방편. 문제 발견의 핵심 단서. |
| 제품 발견 메커니즘 | **Product Discovery Mechanism** | FDE 현장 작업이 곧 팔란티어의 제품을 만들어내는 상류 활동. |
| 4대 플랫폼 | Gotham / Foundry / Apollo / **AIP** | 정보·상업 / 배포 / AI 계층. → [00](00-palantir-overview.md) |
| AI FDE | **AI FDE** | FDE 방법론을 자연어 에이전트로 부분 자동화. 변경은 Branch Proposal로 사람이 리뷰. |
